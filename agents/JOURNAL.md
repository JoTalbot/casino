### Контекст на входе
Репозиторий `JoTalbot/casino` существовал, но был **полностью пустым** — ни одного коммита,
ни инструкций, ни истории. Задача от владельца: настроить репозиторий, создать инструкции
для всех будущих агентов (работа ведётся с разных машин, разными ИИ, в том числе параллельно,
нужно сохранять статус и контекст), и провести глубокое исследование по теме
«как сделать своё личное интернет-казино со слотами».

### Сделано
- **T-001** Репозиторий инициализирован, ветка `main`, `.gitignore`, `README.md`.
- **T-002** Написан `AGENTS.md` v1.0 — полный протокол работы агентов:
  - правила git (pull --rebase, атомарные коммиты, push сразу, Conventional Commits);
  - идентификация агента (`<модель>-<дата>-<буква>`);
  - **файловые локи** в `agents/locks/` для параллельной работы, разрешение гонок «кто первый запушил»;
  - чеклисты начала и конца смены;
  - форматы JOURNAL / TASKS / DECISIONS;
  - правила исследования (всё со ссылками, разделять факт и оценку);
  - правила кода (CSPRNG, серверный RNG, деньги в целых, полный лог раундов);
  - юридическая рамка §11 — запрет на реальные деньги без лицензии;
  - таблица анти-паттернов.
- **T-003** Создана система сохранения контекста: `STATE.md`, `HANDOFF.md`, `TASKS.md`,
  `JOURNAL.md`, `DECISIONS.md`, `QUESTIONS.md`, `GLOSSARY.md`, `locks/`.
