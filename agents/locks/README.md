# locks/ — файловые локи для параллельной работы агентов

Механика описана в `AGENTS.md`, раздел про локи. Кратко:

- Имя файла: `<область>.lock`, где область — одна из:
  `engine`, `math`, `research`, `docs`, `frontend`, `backend`, `infra`.
- Содержимое — YAML:

```yaml
agent: claude-2026-08-17-A
task: T-007
scope: math
started: 2026-08-17T10:00:00Z
expires: 2026-08-17T16:00:00Z
note: калибровка reel strips под RTP 96%
```

- Владеет локом тот, кто **первым запушил** файл на GitHub.
- Если `expires` в прошлом — лок протух, его можно удалить и взять область себе,
  записав это в `agents/JOURNAL.md`.
- `STATE.md`, `JOURNAL.md`, `TASKS.md`, `QUESTIONS.md` **не блокируются** —
  они правятся всеми через `git pull --rebase`.
- Снимая лок, удаляй файл тем же коммитом, что и результат работы.
