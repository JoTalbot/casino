# GLOSSARY.md — Термины отрасли

Справочник для агентов, впервые попавших в проект.

---

## Математика слотов

| Термин | Расшифровка | Значение |
|---|---|---|
| **RTP** | Return To Player | Доля ставок, возвращаемая игрокам на длинной дистанции. Онлайн-слоты обычно 94–97%. |
| **House Edge** | Преимущество казино | `100% − RTP`. При RTP 96% — 4%. |
| **Hit Frequency** | Частота выигрышей | Доля спинов с любым выигрышем. Типично 20–35%. |
| **Hit Rate** | То же в формате «1 из X» | Hit frequency 30% = hit rate 1 к 3.33. |
| **Volatility / Variance** | Волатильность | Низкая — частые мелкие выигрыши; высокая — редкие крупные. |
| **PAR sheet** | Probability Accounting Report | Главный математический документ игры: reel strips, веса символов, таблица выплат, расчёт RTP. Подаётся в сертификационную лабораторию. |
| **Reel Strip** | Лента барабана | Полный список символов по позициям одного барабана. |
| **Virtual Reel** | Виртуальный барабан | Отображение физических стопов на большее число виртуальных позиций с весами. Патент Telnaes (1984) — основа современных джекпотов. |
| **Payline** | Линия выплат | Траектория, по которой считаются совпадения. |
| **Ways to Win** | Способы выиграть | Механика без фиксированных линий (243, 1024 способа). |
| **Megaways** | Мегавейс | Механика с переменным числом символов на барабане, до 117 649 способов. |
| **Wild** | Дикий символ | Заменяет другие символы. Резко повышает hit frequency и RTP. |
| **Scatter** | Скаттер | Платит/триггерит независимо от позиции на линии. Обычно запускает фриспины. |
| **Free Spins** | Фриспины | Бонусные вращения без списания ставки. |
| **Retrigger** | Ретриггер | Повторный запуск фриспинов внутри бонуса. Обязателен к учёту в RTP через формулу бесконечного ряда. |
| **Full Cycle** | Полный цикл | Все возможные комбинации стопов по одному разу. Основа точного расчёта RTP. |
| **Monte Carlo** | Монте-Карло | Симуляция миллионов спинов для проверки RTP. Стандарт — от 10 млн. |
| **Max Win** | Максимальный выигрыш | Потолок выплаты, обычно в множителях ставки (500x … 50000x). |
| **Bonus Buy** | Покупка бонуса | Мгновенный вход в фриспины за плату. Запрещён в ряде юрисдикций. |

## Технологии

| Термин | Значение |
|---|---|
| **RNG** | Random Number Generator — генератор случайных чисел. |
| **PRNG / CSPRNG** | Псевдослучайный / криптостойкий псевдослучайный генератор. В казино допустим только CSPRNG. |
| **Provably Fair** | Схема, где игрок может криптографически проверить честность каждого раунда постфактум. |
| **Server Seed** | Секрет сервера, публикуемый заранее в виде SHA256-хэша (коммитмент). |
| **Client Seed** | Seed игрока — гарантия, что оператор не контролирует исход единолично. |
| **Nonce** | Счётчик ставок, обеспечивающий уникальность каждого раунда при тех же seed'ах. |
| **Commit-Reveal** | Схема: сначала публикуем хэш секрета, потом раскрываем секрет. |
| **VRF** | Verifiable Random Function — проверяемая случайность on-chain (Chainlink, ORAO). |
| **RGS** | Remote Game Server — сервер, где считается игровая логика и хранятся исходы. |
| **PAM** | Player Account Management — модуль аккаунтов, кошельков, бонусов, лимитов. |
| **Seamless Wallet** | Единый кошелёк: игра не хранит баланс, а дёргает API платформы на каждую ставку. |
| **Аггрегатор** | Поставщик, дающий тысячи игр разных провайдеров через одну интеграцию. |
| **Turnkey / White Label** | Готовая платформа под ключ / под чужой лицензией и брендом. |

## Бизнес и финансы

| Термин | Значение |
|---|---|
| **GGR** | Gross Gaming Revenue = ставки − выплаты. Основная метрика дохода. |
| **NGR** | Net Gaming Revenue = GGR − бонусы − комиссии провайдеров − роялти. База для rev share. |
| **Rev Share** | Доля дохода, отдаваемая провайдеру/платформе/аффилиату. |
| **CPA** | Cost Per Acquisition — фиксированная плата за привлечённого игрока. |
| **LTV** | Lifetime Value — сколько игрок приносит за всё время. |
| **Retention** | Удержание игроков. |
| **Bonus Abuse** | Злоупотребление бонусами (мультиаккаунты, арбитраж). |
| **Chargeback** | Возвратный платёж. Больная тема гемблинга. |
| **PSP** | Payment Service Provider. Гемблинг — категория high-risk. |

## Право и комплаенс

| Термин | Значение |
|---|---|
| **KYC** | Know Your Customer — верификация личности игрока. |
| **AML / CFT** | Противодействие отмыванию денег и финансированию терроризма. |
| **UBO** | Ultimate Beneficial Owner — конечный бенефициар. Проверяется при лицензировании. |
| **Responsible Gambling** | Ответственная игра: лимиты депозитов, самоисключение, reality check. |
| **Self-exclusion** | Самоисключение игрока. Обязательный механизм в регулируемых рынках. |
| **GLI-11** | Стандарт Gaming Laboratories International для игровых устройств и RNG. |
| **eCOGRA / iTech Labs / BMM** | Аккредитованные лаборатории сертификации RNG и математики. |
| **MGA** | Malta Gaming Authority — «золотой стандарт» лицензий. |
| **CGA / LOK** | Curaçao Gaming Authority и новый закон Кюрасао о ставках. |
| **Anjouan (ABGB)** | Бюджетная офшорная юрисдикция (Коморские острова). |
| **KGC** | Kahnawake Gaming Commission (Канада). |
| **Sub-licence** | Сублицензия. На Кюрасао отменена — теперь только индивидуальные лицензии. |
