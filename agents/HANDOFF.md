## Прогресс T-026

`e1c9238` подключил `POST /api/v1/rounds` к Fastify. Маршрут требует:
- действующий JWT;
- `Idempotency-Key` (1…128);
- `gameCode: crown-of-fortune`, целые положительные `betPerLine` и `lines`.

Он вызывает serializable `settleRound()` и возвращает 201 при новом раунде,
200 при повторе ключа, 409 для доменных конфликтов. Активный server seed не
выдаётся. `npm run typecheck` зелёный.
