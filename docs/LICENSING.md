# Что нужно, чтобы играть на реальные деньги

> Документ отвечает на прямой вопрос владельца: «давай включим реальные
> деньги». Короткий ответ — нельзя одной настройкой. Ниже что именно
> требуется, сколько это стоит и что из этого у нас уже готово.
>
> Дата проверки: 2026-08-20. Регуляторные требования меняются — перед
> любыми действиями сверяйтесь с официальным реестром PlayCity.

## 1. Юридическая рамка (Украина)

С 1 апреля 2025 года рынок регулирует государственное агентство
**PlayCity** (подчинено Минцифре). Комиссия КРАІЛ ликвидирована, её
функции переданы новому регулятору. Работа онлайн-казино **без лицензии
незаконна**: это не «серая зона», а основание для блокировки, штрафов и
уголовной ответственности.

| Требование | Порядок величины |
|---|---|
| Лицензия на онлайн-казино | ~30–39 млн грн (привязана к минимальной зарплате: 6 500 МЗП), срок 5 лет |
| Банковская гарантия | ~12 млн грн |
| Юридическое лицо | резидент Украины, раскрытие структуры собственности и происхождения средств |
| Домен | зона `.ua`, принадлежащий зарегистрированной торговой марке |
| Возраст игроков | **21+** (не 18) |
| Верификация | обязательная: Дія / BankID / KYC-провайдер |
| Софт | только **сертифицированный**, проверка поставщиков регулятором |
| AML | процедуры финмониторинга, отчётность |
| Аудит | внутренние проверки ежеквартально |
| Налоги | удерживаются с выигрышей игроков |
| Поддержка | на украинском языке, публичные правила игр |

Отдельно: **Telegram запрещает азартные игры на реальные деньги** в
мини-аппах и ботах. Даже с лицензией распространение через нашего бота
потребует отдельного согласования, иначе бот будет заблокирован.

## 2. Сертификация игры

Лицензии недостаточно — сама математика и RNG проходят независимую
лабораторию (GLI, BMM, iTech Labs и т. п.):

- **GLI-19** (интернет-системы) и **GLI-11** (игровые устройства) —
  типовые стандарты для слотов;
- сертифицируется конкретная версия конфигурации: наш `config/game.json`
  с хэшем `a5852c7e…` — при любой перекалибровке сертификат нужно обновлять;
- проверяется генератор случайных чисел, заявленный RTP, поведение при
  сбоях и восстановление незавершённых раундов.

## 3. Что у нас уже есть (и это немало)

Технически проект готов лучше, чем кажется: значительная часть требований
лаборатории закрыта не потому, что мы шли к лицензии, а потому что иначе
не бывает честной игры.

| Требование | Статус |
|---|---|
| Деньги целыми числами, двойная запись | ✅ `ledger_entries`, баланс — производная от журнала |
| Идемпотентность денежных операций | ✅ уникальный ключ на каждую проводку |
| Неизменяемость журнала | ✅ триггеры запрещают UPDATE/DELETE |
| Полный лог раунда для переигровки | ✅ сиды, nonce, ставка, сетка, выплата |
| Provably fair и офлайн-верификатор | ✅ `verifier/verify.html` |
| Серверный RNG на CSPRNG | ✅ HMAC-SHA256, клиентской случайности нет |
| Ответственная игра: лимиты, самоисключение, reality check | ✅ реализовано |
| Возрастной гейт | ⚠️ 18+, для Украины нужно **21+** |
| Аудит действий | ✅ `audit_log` |
| Экспорт данных игрока (GDPR) | ✅ `/me/export` |
| KYC | ❌ нет |
| AML-мониторинг | ❌ нет |
| Платёжный контур | ❌ нет |
| Сертификация RNG и математики | ❌ нет |
| Лицензия | ❌ нет |

## 4. Порядок действий, если решение принято

1. **Юрист по игорному праву** — до всего остального. Структура владения,
   налоги, требования к капиталу.
2. Регистрация юрлица и торговой марки, домен `.ua`.
3. Подготовка пакета документов для PlayCity, банковская гарантия.
4. Параллельно: сертификация софта в лаборатории.
5. Договоры с платёжными провайдерами (они сами потребуют лицензию).
6. Внедрение KYC (Дія/BankID), AML-процедур, возраста 21+.
7. Только после получения лицензии — включение денежного режима в коде.

## 5. Технический предохранитель

Чтобы денежный режим нельзя было включить «случайно одной переменной»,
в `src/server/app.ts` стоит проверка `assertMoneyModeAllowed`:

- `MONEY_MODE=real` без `GAMBLING_LICENSE_ID` — сервер не стартует;
- `MONEY_MODE=real` с номером лицензии — сервер тоже не стартует, потому
  что платёжного контура, KYC и сертификации нет.

Снимать этот предохранитель имеет право только человек, у которого на
руках лицензия и сертификат — и он же обязан обновить `agents/STATE.md`,
как требует AGENTS.md §11.

## 6. Что можно делать без лицензии

- Соц-казино на виртуальных фишках (текущий режим) — **промокоды,
  бонусы, турниры, рефералка входят сюда** и уже работают.
- **B2B**: продавать математику и движок лицензированным операторам.
  Здесь лицензия нужна не нам, а покупателю; от нас потребуется
  сертификация софта — это заметно дешевле, чем операторская лицензия.
- Демо-версии для маркетинга лицензированных партнёров.
