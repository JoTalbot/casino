# art/ — исходники символов

`src/*.jpg` — рендеры 1024×1024 на чёрном фоне, как они пришли из генератора.
Игровые текстуры получаются из них скриптом `scripts/build_symbols.py`:
фон вырезается в альфу по яркости, изображение обрезается по содержимому,
приводится к квадрату и масштабируется до 256×256 в `client/public/symbols/`.

Клиент использует **только** `public/symbols/`. Исходники нужны, чтобы
пересобрать текстуры в другом размере или подправить кеинг фона.
