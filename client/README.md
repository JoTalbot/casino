# client — прототип клиента слота

PixiJS v8 + [`pixi-reels`](https://github.com/schmooky/pixi-reels) + GSAP,
сборка Vite. Показывает раунд игры «Crown of Fortune» (5×3, 20 линий).

## Главное правило

**Клиент не решает исход.** Он отправляет ставку, получает от сервера
готовую сетку и только показывает её. В коде нет ни одной строки,
способной сгенерировать результат:

- сетка приходит в `RoundRecord.spins[].grid` и передаётся в
  `reelSet.setResult()` без изменений;
- `.weights()` и `.rng()` библиотеки влияют исключительно на символы,
  мелькающие **во время** вращения, — к результату они отношения не имеют;
- предвкушение (`anticipation`) считается по уже известной серверной
  сетке, то есть подаёт исход, а не влияет на него.

Проверяется это не на словах: `src/reels.test.ts` прогоняет все 136 спинов
из `tests/fixtures/rounds.json` через настоящий `ReelSet` и сверяет каждую
ячейку с серверной сеткой.

## Запуск

Из корня репозитория (нужен работающий сервер раундов на :3001):

```bash
npm run dev:server     # терминал 1
npm run dev:client     # терминал 2
```

Либо прямо здесь: `npm install && npm run dev`.

Обращения к API идут по относительному пути `/api/v1/...`; Vite
проксирует их на `127.0.0.1:3001` (см. `vite.config.ts`). Прямые ссылки
на `localhost:3001` в коде клиента запрещены — у стороннего зрителя
`localhost` указывает на его собственную машину.

## Тесты

```bash
npm test
```

- `src/presentation.test.ts` — чистые функции показа: перевод сетки,
  подсветка выигрышей без дублей, предвкушение, категории выигрыша.
- `src/reels.test.ts` — интеграция с барабанами через headless-харнесс
  `pixi-reels/testing`; ни браузера, ни текстур не требуется.

Заглушка `navigator` в `vitest.setup.ts` нужна потому, что PixiJS
обращается к нему прямо при импорте модуля.

## Файлы

| Файл | Назначение |
|---|---|
| `src/main.ts` | сборка сцены, цикл раунда, обработчики интерфейса |
| `src/api.ts` | типизированный клиент REST |
| `src/presentation.ts` | чистая логика показа (вся покрыта тестами) |
| `src/symbols.ts` | символы, нарисованные через `Graphics` |
| `index.html` | вёрстка и стили панелей вокруг канваса |

Символы рисуются кодом, а не картинками: прототипу нужны читаемые
различимые фигуры, а не арт. Заменить на спрайты можно, переписав
`ShapeSymbol.draw()` — остальной код о графике ничего не знает.
